# MoonBit Feature Forge 扩展设计

## 1. 目标与边界

MoonBit Feature Forge 将从一个能够运行 FAST-9、ORB、二进制描述子匹配和仿射 RANSAC 的原型，扩展为一个可复用的纯 MoonBit 2D 局部特征工具包。库面向 WebAssembly、Native、JavaScript 等稳定后端，服务于图像配准、目标跟踪、轻量级检索、拼接前端和边缘视觉预处理等场景。

本次交付的成功标准是：

1. 核心实现覆盖完整的图像数据、预处理、特征、匹配和几何验证链路。
2. 生产实现本身达到 8,000 行以上真实有效 MoonBit 源码；测试、CLI 和示例另行统计，最终以仓库中的统计命令输出为准。
3. 所有公开能力都有稳定的边界行为和可运行测试；退化输入不会越界或产生未解释的崩溃。
4. CLI 使用与库 API 相同的实现，能运行 demo 和 benchmark，并输出实际测量结果。
5. README、CI、LICENSE、包元数据和 Mooncakes 发布流程可供新用户复现。

明确不在本次范围内的内容：彩色图像编解码、外部 C/C++ 绑定、神经网络模型、相机驱动、GUI 和 GitLink 发布操作。输入保持为库内的灰度图像与已构造的像素数据，避免把图像格式依赖引入核心包。

## 2. 设计路线

采用单一公共根包、按职责拆分源文件的架构。用户只需要引入 `Myytsjj/moonbit-feature-forge`，公共类型和函数保持集中；实现按文件组织，避免为了拆包而暴露内部类型或引入循环依赖。CLI 保持在 `cmd/main`，只调用根包 API。

文件边界遵循以下规则：单个文件尽量小于 2,000 行；单个函数尽量小于 200 行；每个新增公共 API 同时补充文档和黑盒测试；内部辅助函数不加 `pub`。

## 3. 模块与数据流

### 3.1 图像与采样

增强 `GrayImage` 的创建、读取和写入能力，提供：

- 有效尺寸校验和安全的越界读取策略；
- `Point2`、`FloatPoint2`、`Rect` 等几何基础类型；
- crop、fill、clone、直方图和灰度归一化；
- clamp、reflect、constant 等边界模式；
- 最近邻和双线性采样；
- 生成平移、旋转、缩放后的合成图像，用于示例和确定性测试。

### 3.2 预处理与尺度空间

增加 box blur、Gaussian 近似、Sobel 梯度、梯度幅值/方向、局部对比度和图像金字塔。每一层保存缩放因子，并提供原图坐标与金字塔坐标之间的映射。滤波器不修改输入图像，输出新图像，便于复用和测试。

### 3.3 FAST 与 ORB

保留现有便捷函数，新增配置对象支持：阈值、连续像素数、NMS、边界大小、每层最大特征数和最小响应值。FAST 输出响应稳定排序的关键点；ORB 负责方向估计和 256 位旋转 BRIEF 描述子，明确处理 patch 不完整、常量 patch 和角度归一化。

多尺度提取器在每一层运行检测与描述，再把关键点坐标、尺寸和响应映射回原图。排序规则固定为响应降序、坐标升序，保证相同输入与种子得到可重现结果。

### 3.4 描述子匹配

扩展当前汉明距离实现，加入：

- 描述子长度不一致时的明确行为；
- Top-K 邻近匹配与稳定排序；
- Lowe ratio test、mutual cross-check、唯一训练索引约束；
- 距离均值、最小值、最大值和分位统计；
- 面向固定长度二进制描述子的轻量索引，索引失效时回退到穷举匹配。

所有过滤器都返回新数组，不在调用者数据上隐式修改顺序；空查询、空训练集和 `k <= 0` 都有确定结果。

### 3.5 几何模型与鲁棒估计

保留 `AffineTransform`，补充：

- 点集转换和逆变换；
- 3 点仿射估计的退化检测与残差统计；
- 4 点单应性估计、齐次坐标投影和四边形变换；
- 统一的重投影误差、内点掩码和模型诊断结构；
- 仿射与单应性 RANSAC，使用确定性随机源、最小样本退化检查、早停和可选模型重估。

RANSAC 输入索引越界、样本不足、阈值无效和全部样本退化时返回身份模型与可解释的诊断状态，不通过除零或数组越界来表达失败。随机种子作为配置项暴露，默认值保持确定性。

### 3.6 端到端 Pipeline

新增 `FeatureConfig`、`FeatureSet`、`MatchReport` 和 `PipelineResult`。端到端流程为：

```text
GrayImage
  -> optional preprocessing
  -> pyramid
  -> FAST keypoints
  -> orientation + ORB descriptors
  -> KNN / ratio / cross-check
  -> affine or homography RANSAC
  -> inlier and quality report
```

旧的 `extract_features`、`match_and_filter` 和 `full_feature_pipeline` 继续作为默认配置的便捷入口，避免破坏现有使用方式。新 API 的复杂配置集中在配置结构中，不把参数列表无限扩展到每个函数。

## 4. 错误处理与确定性

核心算法保持纯数据变换风格。对于可以正常表示的空结果使用空数组；对于需要区分失败原因的估计流程，返回带状态和诊断字段的结果结构。所有随机采样使用显式种子；默认种子固定，CLI 可覆盖。浮点比较使用调用者提供的容差或项目统一的小阈值，不使用未经说明的精确相等判断来决定几何模型有效性。

公开函数的边界约定写入文档和测试，重点覆盖负尺寸、零尺寸、越界坐标、极小图像、边界 patch、空数组、长度不匹配、重复描述子、共线样本和无内点输入。

## 5. CLI 与真实基准

`cmd/main` 提供默认 demo，并支持明确的 demo/benchmark 分支。benchmark 使用固定尺寸和固定合成场景，分别测量预处理、检测、描述、匹配和几何验证阶段，输出：

- 工具链版本和目标后端；
- 图像尺寸、特征数量、候选匹配数、内点数量和内点率；
- 每个阶段的耗时和总耗时；
- 使用的阈值、比例、RANSAC 迭代次数和随机种子。

README 中只记录实际执行产生的结果，并标注机器、日期、后端和命令。基准结果用于回归比较，不宣称跨机器的绝对性能排名。

## 6. 测试策略

测试分为四层：

1. 数据层：尺寸、像素夹紧、边界模式、裁剪、采样、直方图和归一化。
2. 算法层：滤波、梯度、金字塔、FAST、方向、ORB、汉明距离、匹配过滤、仿射和单应性估计。
3. 退化与边界层：空输入、极小输入、常量图、低对比度、patch 越界、重复描述子、无训练集、`k` 边界、共线点、重复点、无内点和无效阈值。
4. 集成层：固定合成场景中的平移、旋转、缩放、异常匹配和端到端 pipeline；验证确定性、内点率、残差上界和输出数量关系。

测试使用稳定断言验证科学计算结果，只有结构化诊断输出才使用快照。覆盖率用于发现未触达分支，但不以覆盖率数字代替正确性；最终报告测试总数、通过数、覆盖率和实际基准输出。

## 7. CI、格式与发布

CI 采用官方 MoonBit 安装脚本，按 Linux、macOS、Windows 矩阵运行。每个平台执行：

```text
moon version --all
moon update
moon fmt && git diff --exit-code
moon check --deny-warn --target all
moon test --deny-warn --target all
moon info && git diff --exit-code
moon run cmd/main
```

如某后端受运行器限制，CI 会通过明确的 job 或命令标注原因，不静默跳过核心验证。生成物、构建目录、覆盖率临时文件和本地研究缓存加入 `.gitignore`。

`moon.mod` 保持 `Myytsjj/moonbit-feature-forge` 命名空间、Apache-2.0 许可证和 GitHub 仓库元数据。实现完成后先执行本地 dry-run、完整测试和版本检查，再用已授权的 MoonBit 凭据发布；GitHub 推送与 Mooncakes 发布分别记录结果，不把发布成功写成未经命令验证的 README 宣称。
